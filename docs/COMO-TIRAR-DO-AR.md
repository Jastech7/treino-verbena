# Como tirar o Treino Verbena do ar

O site está publicado de forma pública, só para uso pessoal e de poucas pessoas. Quando quiser parar, há duas formas. Use a (a) se só quiser que o site saia do ar. Use as duas se quiser também que o código saia da internet.

## (a) Desativar o site (GitHub Pages)

1. Abra o navegador e entre em https://github.com/Jastech7/treino-verbena
2. Clique na aba **Settings** (Configurações), no alto da página.
3. No menu da esquerda, clique em **Pages**.
4. Em **Build and deployment** (ou **Source**), mude a origem para **None** (nenhuma). Se o botão for outro, procure a opção que desliga a publicação.
5. Confirme. Em alguns minutos o endereço https://jastech7.github.io/treino-verbena/ deixa de abrir.

## (b) Deixar o repositório privado

1. Na mesma página do repositório, clique em **Settings**.
2. Role até o fim do menu da esquerda, e clique em **General** (Geral).
3. Role a página até o final, até a área **Danger Zone** (Zona de perigo).
4. Clique em **Change visibility** (Alterar visibilidade).
5. Escolha **Change to private** (Tornar privado) e confirme, digitando o nome do repositório quando o GitHub pedir.

Depois disso, só você consegue ver o código e os arquivos. Se quiser publicar de novo, é só reverter: deixar o repositório público e ativar o Pages de novo pela mesma tela.

## Observação

Se o repositório for privado, o GitHub Pages pode deixar de funcionar no plano gratuito. Isso não apaga nada: os arquivos continuam no repositório.
